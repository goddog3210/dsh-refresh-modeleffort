# dsh-vm

DSH 本地插件：在输入框下方增加前端刷新按钮，并将原生的「模型与推理等级」入口拆分为独立按钮。

## 能力范围

插件只复用 DSH 原生模型选择器，不会自行声明模型是否支持推理等级，也不会向模型服务商伪造推理参数。

- DSH 原生菜单已提供推理等级时：插件显示当前等级，并将「推理等级」按钮路由到对应的原生设置页。
- DSH 没有渲染当前等级时：插件会先尝试从原生菜单确认该入口；无法确认时会恢复原始 DSH 控件，而不会把「推理等级」点击错误地跳转到模型选择页。
- 因此，若某个模型（例如自定义网关里的 GPT 别名）在原生 DSH 菜单中也没有推理等级，需在 DSH 的模型/Provider 配置或上游网关中启用并暴露该能力；此插件无法单独开启它。

## 推理等级适配

插件复用 DSH 原生模型选择器及其已配置的推理等级，不根据模型名称推断能力，也不会自动修改 Provider 或模型配置。请在 DSH 的模型/Provider 设置中声明支持的等级和对应上游参数；配置后，本插件只负责将原生模型与推理强度入口分开显示，并调用 DSH 原生菜单。

DSH 未提供推理等级时，插件保留原生选择器作为后备，不会伪造等级或请求参数。

## 刷新控制

从 DSH 左侧应用栏打开「刷新控件」页面后，可分别开关：

- 模型与推理强度分开显示（关闭后恢复原生组合按钮，刷新按钮仍可独立启用）；
- 模型选择器左侧的 `↻` 前端刷新按钮；
- 绑定为 `page.refresh` 的快捷键（包括常见的 Ctrl+R）是否刷新 DSH 前端。

以上选项保存在当前客户端的 localStorage 中，不依赖服务端 RPC 或插件配置编辑服务；重新加载页面后仍会生效，但不跨客户端同步。只有本地保存成功后才会更新开关状态。保存失败时保留上次已确认的设置，并显示错误和重试操作。
